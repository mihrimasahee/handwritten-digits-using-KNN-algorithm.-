# 🖋️ Handwritten Digits Classification using KNN
This project demonstrates a basic implementation of a K-Nearest Neighbors (KNN) classifier to recognize handwritten digits using the popular MNIST dataset. It is built in Python using scikit-learn and other data science libraries within a Jupyter Notebook.

## 📂 Project Structure
HandProject_Work.ipynb — Main notebook containing code for:

- Data loading and visualization

- Preprocessing the images

- Training a KNN model

- Evaluating model accuracy and performance

## 🔍 Features
- Uses the MNIST digits dataset (from sklearn.datasets)

- Simple and interpretable KNN classifier

- Visual representation of digit samples

- Accuracy evaluation with confusion matrix and classification report

## ⚙️ Technologies Used
- Python

- Jupyter Notebook

- scikit-learn

- NumPy

- Matplotlib
